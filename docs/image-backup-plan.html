디스크를 파일로 떠두고 나중에 그대로 복원한다. 클론 엔진을 재사용해 최소 코드로 구현하는 설계.

미착수 — 계획 작성 2026-07-24 기반 v0.8.8

핵심 통찰

엔진을 그대로 재사용한다

클론 엔진은 IBlockDevice만 안다. 이미지 파일도 하나의 “디스크”로 보면 — 백업은 디스크→이미지 클론, 복원은 이미지→디스크 클론이 된다. 스마트 클론·복제 후 검증·GPT 보정·Universal Restore·부팅 복구가 전부 자동으로 딸려온다.

스마트 클론 해시 검증 GPT 보정 Universal Restore 부팅 검사·복구 SafetyGuard

포맷 결정 — 여기서 방향이 갈린다

v1 권장

A · VHDX

Windows VirtualDisk API

  • +CreateVirtualDisk(동적)→AttachVirtualDisk로 디스크로 마운트 → 기존 whole-disk 클론 엔진 그대로
  • +동적 VHDX는 쓴 블록만 할당 → 스마트 클론과 만나면 사용 영역만 저장(자동 희소)
  • +탐색기·diskpart로 마운트해 파일 꺼내기, Hyper-V 부팅 가능
  • +새 포맷 코드 최소 — tools/DiskMigrator.VhdTest로 VHD 경험 있음
  • −백업·복원 중 가상 디스크가 잠깐 시스템에 붙음, 압축은 별도
대안

B · 커스텀 .dmimg

희소 + 압축

  • +스마트 클론의 사용 런 목록 + 블록 데이터 + 내장 Deflate/Brotli 압축
  • +더 작음(압축), 추가 디스크 안 붙음
  • −DiskMigrator만 복원 가능(독점 포맷)

압축이 정말 필요하면 A 이후 추가.

새 컴포넌트 — A 기준

# DiskMigrator.Windows/
Devices/VirtualDiskApi.cs      Create/Attach/Detach VHDX (virtdisk.dll P/Invoke)
Jobs/BackupOrchestrator.cs     디스크 → VHDX  (VSS 스냅샷 + 스마트 클론 + 검증)
Jobs/RestoreOrchestrator.cs    VHDX → 디스크  (SafetyGuard + GPT보정 + UR + 부팅복구)

메타데이터는 VHDX가 크기·지오메트리를 보존한다. 원본 모델·클론 시각은 사이드카 .json에 기록. 검증은 복제-중-해시 로그를 그대로 재사용.

안전장치 — 기존 규칙 재사용

백업(디스크→파일) — 라이브 시스템은 VSS 스냅샷(클론과 동일), 대상 경로의 여유 공간 사전 확인, FAT32면 4GB 한계 경고(NTFS/exFAT 권장).

복원(파일→디스크) — 대상 디스크를 파괴하므로 SafetyGuard 그대로: 시스템 디스크 차단, 모델명 직접 입력 확인, 쓰기 직전 재확인. 복원 후 자동 부팅 검사·복구·(옵션)UEFI 변환까지 클론과 동일하게 연결.

⚠︎ 복원은 대상 디스크의 모든 데이터를 되돌릴 수 없이 덮어쓴다. 클론과 똑같은 안전 관문을 통과해야 진행된다.

UI / CLI

시작 화면에 모드 선택을 추가한다 — 디스크 클론 · 이미지 백업 · 이미지 복원. 백업은 원본 디스크 + 저장 경로 + 옵션(스마트/압축), 복원은 이미지 파일 + 대상 디스크 + 확인. 진행률·검증 화면은 클론과 공유.

# 파일 기반으로 실디스크 없이 테스트 가능(VhdTest에 추가)
DiskMigrator.VhdTest.exe --backup  <디스크> <파일>
DiskMigrator.VhdTest.exe --restore <파일> <디스크>

단계별 진행

  1. 엔진
    VirtualDiskApi + 두 오케스트레이터를 IBlockDevice로 연결. VHD 대상 테스트(실디스크 불필요).
  2. CLI + 통합 테스트
    --backup/--restore + VHD↔VHD end-to-end(chkdsk 클린·해시 일치).
  3. 복원 후처리
    GPT 보정·리사이즈·UR·부팅 복구 연결 — 클론 오케스트레이터 로직 공유.
  4. GUI
    모드 선택 + 백업/복원 화면.
  5. 실기 검증
    실제 시스템 백업 → 복원 → 부팅.
  6. 선택: 압축·분할
    커스텀 포맷 또는 VHDX 후처리 압축, FAT32 분할.

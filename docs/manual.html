사용설명서 — 윈도우가 설치된 디스크를 통째로 복사·보관·복원하는 도구 (컴퓨터 초보자용 안내) v1.1.0

시작 전에 세 갈래 디스크 복사 이미지 백업 이미지 복원 부팅 복구 부팅 USB Claude 연결 USB와 내부 연결 FAQ 용어 설명 English

지금 쓰는 컴퓨터의 디스크를 윈도우·프로그램·파일까지 통째로 새로운 디스크에 복사하거나, 파일 하나로 만들어 보관했다가 나중에 필요시 되돌립니다. 복사된 디스크는 그대로 부팅되므로 윈도우를 새로 설치할 필요가 없습니다.

예: 느린 하드디스크 → 새 SSD로 이사, 고장 대비 전체 백업, 새 컴퓨터로 시스템 옮기기

시작하기 전에 (꼭 읽어주세요)

⚠ 대상 디스크는 완전히 지워집니다. 복사를 "받는" 쪽 디스크의 기존 내용은 모두 사라집니다. 중요한 파일이 있다면 먼저 옮겨 두세요.

• 프로그램은 관리자 권한으로 실행됩니다(실행 시 파란 창이 뜨면 "예").

• 새 디스크(M.2/SSD)를 연결할 USB 어댑터(외장 케이스)가 있으면 편리합니다.

• 데이터 양에 따라 30분~수 시간 걸립니다. 도중에 컴퓨터를 끄지 마세요.

세 갈래로 시작합니다 — 화면 위쪽에서 선택

디스크 복사 — 따라하기

화면 위쪽 [디스크 복사]

  1. 원본(복사할 디스크, 보통 시스템 표시)을 왼쪽에서 선택
  2. 대상(새 디스크)을 오른쪽에서 선택 — 이 디스크가 지워집니다
  3. 옵션은 기본값 그대로 두고, 다른 컴퓨터로 옮길 거면 "새 하드웨어 대비" 체크 확인
  4. 빨간 칸에 대상 디스크의 모델명을 그대로 입력 (실수 방지 장치입니다)
  5. 클론 시작 → 완료되면 부팅 검사·복구까지 자동으로 진행됩니다
✓ 크기가 달라도 됩니다. 대상이 크면 남는 공간을 쓸 수 있게 해 주고, 대상이 작으면 가장 큰 파티션을 자동으로 줄여 맞춥니다(안내 문구로 알려줌). 실제 데이터가 대상보다 많으면 시작 전에 이유를 알려주고 멈춥니다.

이미지 백업 — 따라하기

화면 위쪽 [백업 · 복원] → [이미지 백업]

✓ 지금 컴퓨터(C:\)를 통째로 파일 하나에 저장해 두세요 (권장)
디스크를 바꾸거나 고장 나도, 복원하면 쓰던 모습 그대로 살아납니다.
  1. 원본 디스크 선택
  2. 저장 위치 선택 — 원본이 아닌 다른 디스크에, 빠른 디스크 권장
  3. 백업 시작 → .vhdx 파일 하나가 만들어집니다 (실제 사용한 용량만큼만 차지)
만들어진 .vhdx 파일은 탐색기에서 더블클릭하면 내용물을 열어볼 수도 있습니다.
✓ 두 번째부터는 훨씬 빠릅니다(증분 백업). 다음 백업 때 저장 위치에서 지난번 백업 파일을 그대로 선택하면, 바뀐 것만 작은 새 파일(backup-01.vhdx 등)에 저장됩니다. 기존 파일은 바뀌지 않으며, 복원할 땐 가장 최근 파일을 고르면 됩니다. 파일들은 같은 폴더에 함께 보관하세요.

이미지 복원 — 따라하기

화면 위쪽 [백업 · 복원] → [이미지 복원]

  1. 찾아보기로 백업해 둔 .vhdx 파일 선택
  2. 대상 디스크 선택 — 지워집니다. 작은 디스크면 자동 축소 안내가 뜹니다
  3. 다른 컴퓨터에서 쓸 거면 "새 하드웨어 대비" 켜기 → 모델명 입력 → 복원 시작
✓ 백업 파일이 온전한지 자동으로 검사합니다. 파일을 고르면 곧바로 구조를 확인해 알려주고, 복원을 시작하면 대상을 지우기 전에 한 번 더 깊이 검사합니다(파일시스템까지). 손상된 백업이면 대상을 건드리지 않고 멈춥니다.

부팅 복구 — 따라하기

화면 위쪽 [문제 해결] → [부팅 복구]

클론·복원해 둔 디스크가 부팅되지 않을 때 쓰는 도구입니다. 복사를 다시 하지 않습니다.

  1. 안 켜지던 디스크를 USB 어댑터 등으로 이 컴퓨터에 연결
  2. [문제 해결] → [부팅 복구]에서 그 디스크 선택
  3. 부팅 검사 누르기 — 읽기만 하므로 안전합니다
  4. 문제가 발견되면 나타나는 부팅 복구 버튼 누르기 — 고친 뒤 자동으로 다시 검사됩니다
지금 컴퓨터가 부팅에 쓰고 있는 디스크는 고칠 필요가 없어 복구가 적용되지 않습니다. 검사 결과에 "부팅 준비됨"이 나오면 디스크를 다시 장착해 부팅해 보세요.
"이 디스크는 오프라인입니다"가 나오면 검사가 실패한 것이 아니라 검사를 할 수 없었던 것입니다. 윈도우가 그 디스크의 볼륨을 연결하지 않아 부팅 파일을 읽지 못한 상태입니다. 안내대로 디스크를 온라인으로 바꾼 뒤 다시 검사하세요. 그 전까지의 결과는 "문제 없음"이 아니라 "확인 못 함"입니다.

진단 리포트 저장 — 다른 사람에게 보여주기

검사 결과가 이해되지 않거나 도움을 받고 싶을 때, 진단 리포트 저장 버튼을 누르면 그 디스크의 부팅 관련 정보를 파일 하나로 모아 줍니다. 디스크는 수정하지 않고 읽기만 합니다.

저장한 파일을 USB로 다른 컴퓨터에 옮겨 Claude에게 보여주거나 저희에게 보내면 됩니다. 부팅이 안 되는 컴퓨터에서 특히 쓸모 있습니다 — 그 컴퓨터에는 인터넷도 Claude도 없지만, 부팅 USB로 부팅해 이 버튼만 누르면 필요한 정보가 전부 담깁니다.

• 디스크 시리얼·볼륨 이름은 기본적으로 가려서 담습니다. 남에게 보여줄 파일이기 때문입니다.
• 리포트는 진단 대상 디스크에는 저장할 수 없습니다. USB나 다른 디스크를 고르세요.
• 고치기 전과 후 두 번 저장해 두면 무엇이 바뀌었는지 비교할 수 있습니다.

부팅 USB — 따라하기

화면 위쪽 [문제 해결] → [부팅 USB]

윈도우가 아예 켜지지 않는 컴퓨터를 구조하기 위한 비상용 USB를 미리 만들어 둡니다. 별도 프로그램 설치 없이, 지금 윈도우에 들어 있는 재료만으로 만듭니다.

⚠ USB 메모리는 완전히 지워집니다. 8GB 이상의 빈 USB 메모리를 준비하세요.
  1. USB 메모리를 꽂고 [문제 해결] → [부팅 USB]에서 그 USB 선택
  2. 빨간 칸에 USB의 모델명을 그대로 입력 (실수 방지 장치입니다)
  3. 부팅 USB 만들기 → 몇 분 뒤 완료됩니다

쓰는 방법: 컴퓨터가 안 켜질 때 이 USB를 꽂고 켜면 DiskMigrator-X가 자동으로 실행됩니다. 거기서 백업해 둔 이미지 복원, 디스크 클론, 부팅 복구를 그대로 쓸 수 있습니다.

• USB로 부팅이 안 되면 컴퓨터를 켤 때 부팅 메뉴 키(제조사마다 F12·F8·ESC 등)를 눌러 USB를 선택하세요.
• 미리 만들어 두는 것이 핵심입니다 — 고장 난 뒤에는 다른 컴퓨터에서 만들어야 합니다.

Claude 연결 — 무엇을 해야 할지 물어보기

이 앱의 진단을 Claude가 직접 읽게 하는 기능입니다. 화면 오른쪽 위 Claude 연결에서 켭니다. 기본은 꺼져 있습니다.

무엇이 좋아지나요. "디스크가 안 켜져요"라고만 말해도, Claude가 부팅 파일·드라이버·부팅 흔적을 직접 읽어 어디서 멈췄는지 짚어 줍니다. 화면의 검사 결과를 사람이 해석하지 않아도 됩니다.

가장 쉬운 방법 — 앱에서 바로 물어보기. 문제가 있는 디스크를 고르고 [무엇이 문제인지 봐 줘]를 누르면 끝입니다. 창을 옮겨 다니지 않아도 되고, 아무것도 등록하지 않아도 됩니다. 답은 그 자리에 나옵니다.

이어서 물어볼 수 있습니다. 답 아래 입력 상자에 "그건 왜 그래?", "지금 복제해도 돼?" 처럼 계속 물으시면 됩니다 — 앞의 이야기를 기억합니다. 디스크를 바꿔 꽂으셨다면 [새 대화]로 처음부터 시작하십시오.

이 버튼은 Claude Code가 이 컴퓨터에 있을 때 나타납니다. 없으면 아래 방법으로 Claude 창에서 물어보시면 됩니다. 디스크를 실제로 읽으므로 몇 분 걸릴 수 있고, 진행 상황이 버튼 아래에 표시됩니다.

Claude 창에서 물어보기. 앱 대신 Claude 쪽 창에서 대화하고 싶을 때 씁니다.

  1. Claude에 연결하기 누르기 — 무엇을 고칠지 보여 주면 예
  2. Claude를 완전히 종료했다가 다시 켜기
  3. Claude에게 물어보기 — "이 디스크가 왜 부팅이 안 되는지 봐 줘"

명령 창을 열 필요도, 주소나 토큰을 옮겨 적을 필요도 없습니다. 앱이 Claude 쪽 설정에 자기를 대신 등록합니다. 원래 설정은 같은 자리에 .bak 사본으로 남고, 토큰은 설정 파일에 적히지 않습니다.

등록은 한 번만 하면 됩니다. 다만 앱이 켜져 있어야 Claude가 디스크를 볼 수 있습니다 — 앱을 닫으면 통로도 닫힙니다.

⚠ Claude 앱의 "커스텀 커넥터 추가" 화면으로는 연결되지 않습니다. 그 화면은 주소가 https로 시작할 것을 요구하는데, 이 통로는 이 컴퓨터 안에서만 통하는 http라 거절됩니다. 위의 버튼을 쓰십시오.

버튼이 보이지 않거나 동작하지 않으면, 수동으로 연결하기를 펼쳐 명령 한 줄을 복사해 명령 창에서 실행하는 방법도 있습니다.

⚠ Claude는 디스크를 바꾸지 못합니다. 읽기만 합니다. 복제·백업·복원·부팅 복구는 지금까지처럼 이 화면에서 사용자가 직접 합니다.

Claude가 제안하면 어떻게 되나요. 화면 위쪽에 제안 카드가 뜹니다. 카드에는 무엇을 하자는 것인지, 어느 디스크에서 어디로인지, 왜 그런지가 적혀 있습니다.

• 적용을 누르면 선택만 채워집니다. 실행되지 않습니다.
• 디스크를 지우는 작업(복제·복원)은 그 뒤에도 대상 모델명을 직접 입력해야 시작할 수 있습니다. 이 입력은 Claude가 대신할 수 없습니다.
• 시작 버튼은 언제나 사용자가 누릅니다.

마음에 들지 않으면 무시를 누르세요. 카드는 10분이 지나거나 디스크 구성이 바뀌면 저절로 사라집니다.

Claude가 무엇을 봤는지 확인하기. Claude 연결 패널 아래에 호출 목록이 있습니다. 언제 어떤 도구가 무엇을 대상으로 불렸는지 그대로 보입니다.

• 읽기 — 디스크를 읽기만 했습니다.
• 제안 — 화면에 카드를 띄웠습니다. 실행된 것은 없습니다.
• 붉은 글씨 — 거절된 호출입니다(예: 지금 쓰는 윈도우 디스크를 건드리려 한 경우).

개인정보. 디스크 시리얼·볼륨 이름은 기본적으로 가려서 보냅니다. 진단 내용은 대화 기록에 남으므로, 필요할 때만 "함께 보내기"를 켜세요. 통로는 이 컴퓨터 안에서만 통하며(외부에서 접근 불가), 앱을 닫으면 함께 닫힙니다.

USB로 연결할 때와 내부에 꽂을 때

복사된 내용은 같습니다. 어느 쪽으로 하든 디스크를 그대로 옮기며, 복제 후 검증을 켜면 다시 읽어 원본과 맞춰 봅니다. 다른 것은 그 주변입니다.

무엇이어떻게 다른가
걸리는 시간USB는 내부 연결보다 서너 배 느립니다. 1TB짜리라면 몇 시간 차이가 납니다.
연결이 끊길 위험선이 흔들리거나 절전으로 잠들면 작업이 중단됩니다. 작업 중에는 건드리지 마세요.
디스크 정보USB 어댑터가 디스크의 정보를 원래와 다르게 알려주는 경우가 있습니다. 그래서 같은 디스크인데 USB로 붙였을 때와 내부에 꽂았을 때 값이 달라 보일 수 있습니다. 앱은 이런 경우를 알아채고 위험하면 시작을 막습니다.

이렇게 하시면 됩니다. 급하지 않다면 내부에 꽂는 편이 낫습니다 — 빠르고, 끊길 일이 없고, 정보도 정확합니다. USB로 복사하셨다면 확인은 반드시 내부에 꽂아서 하세요(아래 참조).

복사한 디스크로 부팅하기

① 컴퓨터를 끄고 → ② 복사한 디스크를 컴퓨터 내부에 장착하고 → ③ 켭니다. 끝.

USB 어댑터에 꽂힌 채로는 부팅할 수 없습니다 — 반드시 내부에 장착하세요.

부팅이 안 될 때

당황하지 마세요. 대부분 부팅 설정이 살짝 어긋난 것이라 고칠 수 있습니다. 위의 부팅 복구 — 따라하기 순서대로 하면 대부분 해결됩니다.

• 클론/복원이 끝난 직후라면 완료 화면에도 같은 버튼이 있습니다. (완료 시 자동으로 한 번 실행됩니다.)

• 옛날 방식(BIOS)으로 설치된 윈도우가 요즘 컴퓨터에서 안 켜지면 완료 화면의 UEFI로 변환이 필요합니다.

• 컴퓨터가 아예 안 켜져 이 앱조차 실행할 수 없다면, 미리 만들어 둔 부팅 USB로 부팅해 같은 작업을 할 수 있습니다.

• 오래된 메인보드라면 BIOS를 최신으로 업데이트해 보세요. 특히 재시작은 되는데 껐다 켤 때만 안 되는 경우입니다.

자주 묻는 질문

질문답
원본 디스크가 손상되지 않나요?아니요. 원본은 읽기만 합니다. 어떤 모드에서도 원본은 바뀌지 않습니다.
복사하는 동안 컴퓨터를 써도 되나요?네. 스냅샷 기능이 시작 순간의 모습을 그대로 복사합니다. 다만 무거운 작업은 피하는 게 좋습니다.
왜 모델명을 입력하라고 하나요?지워질 디스크를 정말 확인했는지 묻는 안전장치입니다. 목록에 표시된 이름을 그대로 입력하세요.
시간이 얼마나 걸리나요?사용 중인 데이터 양과 디스크 속도에 달렸습니다. 대략 300GB 기준 30분~1시간입니다.
UEFI로 변환하면 메인보드 설정이 바뀌나요? 아니요. 여기서 말하는 "BIOS"는 메인보드가 아니라 디스크의 옛 부팅 방식입니다. 바뀌는 것은 복사된 디스크 한 장뿐이며, 메인보드 설정도 원본 디스크도 그대로입니다. 다만 되돌릴 수는 없습니다.
UEFI로 변환하면 윈도우 정품 인증이 풀리나요? 아니요. 정품 인증은 주로 메인보드를 기준으로 묶여 있습니다. 디스크의 방식을 바꾸는 것은 부품을 바꾸는 일이 아니라 인증에 영향을 주지 않습니다. 부팅 방식을 UEFI로 바꾸거나 Secure Boot를 켜는 것도 마찬가지입니다.
메인보드 펌웨어(BIOS)를 업데이트하면 인증을 다시 받아야 하나요? 보통은 아닙니다. 다만 드물게 업데이트 과정에서 메인보드의 일련번호가 지워져 다른 컴퓨터로 인식되는 경우가 있습니다. 그럴 때는 설정 → 시스템 → 정품 인증 → 문제 해결에서 "최근에 이 장치의 하드웨어를 변경했습니다"로 되돌릴 수 있습니다 — 미리 Microsoft 계정에 연결해 두어야 이 길이 열립니다.

용어 설명

클론(Clone)
디스크를 다른 디스크로 통째로 복사하는 것. 복사본도 그대로 부팅됩니다.
이미지 / .vhdx
디스크 전체를 담은 파일 한 개. 마이크로소프트 표준 형식이라 탐색기에서 열어볼 수 있습니다.
파티션(Partition)
디스크 안을 나눈 칸. 보통 윈도우용 큰 칸(C:)과 부팅용 작은 칸들이 있습니다.
부팅(Boot)
컴퓨터를 켰을 때 윈도우가 시작되는 과정.
관리자 권한
디스크를 통째로 읽고 쓰려면 필요한 윈도우의 높은 권한. 실행 시 파란 확인 창이 뜹니다.
스냅샷(VSS)
사용 중인 디스크의 "그 순간 모습"을 얼려서 복사하는 윈도우 기능. 복사 중에 파일이 바뀌어도 결과가 안 깨집니다.
스마트 클론
빈 공간은 건너뛰고 실제 데이터만 복사해 시간을 크게 줄이는 기능.
새 하드웨어 대비 (Universal Restore)
복사본을 다른 컴퓨터에 꽂아도 부팅되도록 윈도우 내부 설정을 손봐 주는 기능. 다른 PC로 옮길 땐 꼭 켜세요.
자동 축소
대상 디스크가 원본보다 작을 때, 데이터를 안전하게 앞으로 모아 파티션을 줄여서 맞추는 기능. 원본은 건드리지 않습니다.
BIOS / UEFI
컴퓨터가 켜질 때 제일 먼저 도는 기본 프로그램. BIOS는 옛 방식, UEFI가 요즘 방식이며, 최신 M.2 디스크는 UEFI로만 부팅됩니다.
MBR / GPT
디스크의 칸 나눔(파티션) 정보를 적는 방식. MBR은 옛 방식(BIOS 짝), GPT가 요즘 방식(UEFI 짝)입니다.
M.2 / NVMe / SSD
요즘 쓰는 빠르고 작은 저장장치. M.2는 껌처럼 생긴 모양, NVMe는 빠른 연결 방식, SSD는 반도체 저장장치라는 뜻입니다.
부팅 복구
복사한 디스크의 부팅 설정(BCD)이 어긋났을 때 자동으로 바로잡는 기능. 이 프로그램이 완료 후 자동 실행합니다.
증분 백업
지난 백업 이후 바뀐 부분만 작은 새 파일에 저장하는 백업. 기존 백업 파일을 저장 위치로 다시 고르면 자동으로 진행됩니다. 파일들은 같은 폴더에 함께 보관하세요.
이미지 무결성 검사
복원을 시작하기 전에 백업 파일이 온전한지 자동으로 확인하는 안전장치. 손상된 백업이면 대상 디스크를 건드리지 않고 멈춥니다.

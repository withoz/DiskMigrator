Copy the disk in your current computer — Windows, programs, and files, all of it — onto a new disk, or save it as a single file to bring back later. The copy boots as-is, so there is no need to reinstall Windows.

Examples: move from a slow hard drive to a new SSD, keep a full backup in case of failure, move your system to a new PC

Before you start (please read)

⚠ The target disk is completely erased. Everything on the disk that receives the copy will be gone. Move any important files off it first.

• The program runs with administrator rights (click "Yes" on the blue prompt at launch).

• A USB adapter (external enclosure) for connecting the new disk (M.2/SSD) is handy.

• Depending on the amount of data, it takes 30 minutes to several hours. Do not turn off the computer part-way.

Copy a disk — step by step

Top of the window: [Copy a disk]

  1. Select the source (the disk to copy, usually marked System) on the left
  2. Select the target (the new disk) on the right — this disk will be erased
  3. Leave the options at their defaults; if the disk is going into a different computer, make sure "Prepare for new hardware" is checked
  4. In the red box, type the target disk's model name exactly (this is a mistake-prevention safeguard)
  5. Click Start Clone → when it finishes, the boot check and repair run automatically
✓ Different sizes are fine. If the target is larger, the extra space is made usable; if it is smaller, the largest partition is shrunk automatically to fit (a notice tells you what will happen). If your actual data won't fit on the target, the app explains why and stops before touching anything.

Backup — step by step

Top of the window: [Backup · Restore] → [Backup]

✓ Save your current computer (C:\) into a single file now (recommended)
Even if you replace the disk or it fails, restoring brings everything back exactly as it was.
  1. Select the source disk
  2. Choose the save location — on a different disk than the source; a fast disk is best
  3. Click Start Backup → a single .vhdx file is created (it only takes up as much space as your actual data)
You can also double-click the .vhdx file in File Explorer to browse its contents.
✓ The second time is much faster (incremental backup). On your next backup, pick the previous backup file as the save location — only what changed is saved to a small new file (backup-01.vhdx, and so on). Existing files are never modified; to restore, just pick the most recent file. Keep the files together in the same folder.

Restore — step by step

Top of the window: [Backup · Restore] → [Restore]

  1. Use Browse to pick the .vhdx file you backed up
  2. Select the target disk — it will be erased. If it is smaller, an automatic-shrink notice appears
  3. If the disk will go into a different computer, turn on "Prepare for new hardware" → type the model name → Start Restore
✓ Your backup file is checked automatically. As soon as you pick a file its structure is verified, and when restore starts a deeper check (including the file system) runs before the target is erased. If the backup is corrupted, nothing is written and the target is left untouched.

Boot repair — step by step

Top of the window: [Fix a problem] → [Boot repair]

A tool for when a cloned or restored disk won't boot. It does not copy anything again.

  1. Connect the disk that wouldn't start to this computer, e.g. with a USB adapter
  2. Select that disk under [Fix a problem] → [Boot repair]
  3. Click Check Boot — it only reads, so it is safe
  4. If problems are found, click the Repair Boot button that appears — after repairing, the check runs again automatically
The disk this computer is currently booted from needs no fixing, so repairs are not applied to it. When the check says "ready to boot", put the disk back in its machine and try booting.
If it says "This disk is offline", the check did not fail — it could not run. Windows has not mounted that disk's volumes, so the boot files cannot be read at all. Bring the disk online as the message explains, then check again. Until then the result means "not verified", not "no problems".

Save diagnostic report — to show someone else

When the result is hard to make sense of, or you want help, Save diagnostic report gathers this disk's boot information into a single file. The disk is only read, never modified.

Copy the file to another computer on a USB stick and show it to Claude, or send it to us. This matters most on a computer that will not boot — that machine has no internet and no Claude, but you can start it from the Boot USB and press this one button to capture everything needed.

• Disk serials and volume names are masked by default — this file is meant to be shown to someone else.
• The report cannot be saved onto the disk being diagnosed. Pick a USB stick or another disk.
• Save it before and after a repair to compare what actually changed.

Boot USB — step by step

Top of the window: [Fix a problem] → [Boot USB]

Make an emergency USB ahead of time, to rescue a computer whose Windows won't start at all. Nothing extra to install — it is built entirely from materials already inside your Windows.

⚠ The USB stick is completely erased. Have an empty USB stick of 8 GB or more ready.
  1. Plug in the USB stick and select it under [Fix a problem] → [Boot USB]
  2. In the red box, type the USB stick's model name exactly (a mistake-prevention safeguard)
  3. Click Create Boot USB → done in a few minutes

How to use it: when a computer won't start, plug in this USB and power on — DiskMigrator-X starts automatically. From there you can restore a backup image, clone a disk, or repair the boot configuration, just like normal.

• If the computer doesn't boot from the USB, press the boot-menu key while powering on (F12, F8, ESC, etc., depending on the maker) and pick the USB.
• Making it in advance is the whole point — once a PC is dead, you'd have to build the USB on another computer.

Claude connection — asking what to do

Lets Claude read this app's diagnostics directly. Turn it on under Claude at the top right. It is off by default.

What it gives you. You can just say "my disk won't boot" and Claude reads the boot files, drivers and boot traces itself, then tells you where it stopped. You do not have to interpret the check results.

Easiest way — ask right inside the app. Pick the disk you are worried about and click Tell me what is wrong. That is all. No switching windows, nothing to register. The answer appears right there.

You can keep asking. Use the box under the answer — "why is that?", "can I clone it now?" — it remembers what you talked about. If you swapped a disk, start over with New chat.

This button appears when Claude Code is on this computer. If it isn't, use the method below to ask from the Claude window instead. It really reads your disks, so it can take a few minutes — progress is shown under the button.

Asking from the Claude window. Use this when you would rather talk in Claude's own window.

  1. Click Connect to Claude — it shows what will be changed, then click Yes
  2. Quit Claude completely and start it again
  3. Ask Claude — "have a look at why this disk won't boot"

No command window, no copying addresses or tokens. The app registers itself in Claude's settings for you. Your original settings are kept as a .bak copy in the same place, and the token is never written into the settings file.

You only register once. The app does need to be running for Claude to see your disks — closing the app closes the channel.

⚠ Claude's "Add custom connector" screen cannot connect to this. It requires the address to start with https, but this channel is plain http because it works inside this computer only, so it is rejected. Use the button above.

If the button is missing or does not work, open Connect manually to copy a one-line command you can run in a command window instead.

⚠ Claude cannot change a disk. It only reads. Cloning, backup, restore and boot repair are still done by you, in this window.

What happens when Claude suggests something. A suggestion card appears at the top of the window, saying what it proposes, from which disk to which, and why.

• Apply only fills in the selection. Nothing runs.
• For anything that erases a disk (clone, restore) you must still type the target model name before it can start. Claude cannot do that for you.
• You always press Start yourself.

If you don't like it, click Ignore. Cards disappear on their own after 10 minutes, or if the disks change.

Seeing what Claude looked at. Below the Claude panel there is a call list — when, which tool, and on what.

• Read — the disk was only read.
• Suggestion — a card was put on screen. Nothing ran.
• Red text — the call was refused (for example, trying to touch the Windows disk you are using right now).

Privacy. Disk serials and volume names are masked by default. Diagnostics end up in the conversation log, so turn on "also send" only when needed. The connection works inside this computer only (nothing outside can reach it) and closes with the app.

Over USB versus mounted inside

The copy itself is the same. Either way the disk is moved across as it is, and with Verify after copy turned on it is read back and compared against the source. What differs is everything around it.

WhatHow it differs
TimeUSB is three to four times slower than an internal connection. On a 1 TB disk that is a difference of hours.
Risk of dropping outA knocked cable or a drive going to sleep stops the job. Leave it alone while it runs.
Disk informationA USB adapter sometimes reports the disk's details differently from the disk itself. The same disk can therefore look different over USB than it does mounted inside. The app notices this and refuses to start when it is unsafe.

What to do. Unless you are in a hurry, mounting inside is better — faster, nothing to drop out, and the information is accurate. If you copied over USB, always mount the disk inside to check it (see below).

Booting from the copied disk

① Shut the computer down → ② mount the copied disk inside the computer → ③ power on. Done.

It cannot boot while sitting in a USB adapter — it must be mounted internally.

If it won't boot

Don't panic. It is usually just a slightly misaligned boot setting, and it can be fixed. Following Boot repair — step by step above resolves most cases.

• Right after a clone/restore, the same button is on the completion screen. (It also runs once automatically on completion.)

• If Windows was installed the old way (BIOS) and won't start on a modern computer, use Convert to UEFI on the completion screen.

• If the computer won't turn on at all — so you can't even run this app — boot from the Boot USB you made in advance and do the same work there.

• On an older motherboard, try updating the BIOS to the latest version — especially if a restart works but a cold start does not.

Frequently asked questions

QuestionAnswer
Could my source disk get damaged?No. The source is only read. No mode ever modifies the source.
Can I use the computer while it copies?Yes. The snapshot feature copies the disk exactly as it was at the starting moment. Avoiding heavy work is still a good idea.
Why does it ask me to type the model name?It is a safeguard asking whether you really checked which disk will be erased. Type the name exactly as shown in the list.
How long does it take?It depends on how much data is in use and how fast the disks are. Roughly 30–60 minutes per 300 GB.
Does converting to UEFI change my motherboard settings? No. "BIOS" here means the disk's old boot method, not the motherboard. Only the copied disk changes — your motherboard settings and the source disk are untouched. It cannot be undone, though.
Does converting to UEFI break Windows activation? No. Activation is tied mainly to the motherboard. Changing how a disk boots is not a hardware change, so it does not affect activation. Neither does switching the boot mode to UEFI or turning on Secure Boot.
Do I have to reactivate after a motherboard firmware (BIOS) update? Usually not. Rarely, an update clears the motherboard's serial number and Windows then sees a different computer. If that happens, go to Settings → System → Activation → Troubleshoot and choose "I changed hardware on this device recently" — this route is only open if you linked the licence to a Microsoft account beforehand.

Glossary

Clone
Copying a disk in its entirety onto another disk. The copy boots as-is.
Image / .vhdx
A single file holding an entire disk. It is a Microsoft-standard format, so File Explorer can open it.
Partition
A section a disk is divided into. There is usually one big section for Windows (C:) and a few small ones for booting.
Boot
The process of Windows starting up when you power on the computer.
Administrator rights
The elevated Windows permission needed to read and write whole disks. A blue confirmation prompt appears at launch.
Snapshot (VSS)
A Windows feature that freezes a "moment in time" of a disk in use and copies that. Files changing during the copy can't corrupt the result.
Smart clone
Skips empty space and copies only actual data, cutting the time dramatically.
Prepare for new hardware (Universal Restore)
Adjusts Windows' internal settings so the copy boots even in a different computer. Always turn it on when moving to another PC.
Automatic shrink
When the target disk is smaller than the source, safely gathers the data forward and shrinks the partition to fit. The source is never touched.
BIOS / UEFI
The base program that runs first when a computer powers on. BIOS is the old way, UEFI is the modern way; recent M.2 disks boot only via UEFI.
MBR / GPT
The scheme used to record how a disk is partitioned. MBR is the old one (paired with BIOS); GPT is the modern one (paired with UEFI).
M.2 / NVMe / SSD
Today's fast, small storage. M.2 is the stick-of-gum shape, NVMe is the fast connection, SSD means solid-state storage.
Boot repair
Automatically corrects the boot configuration (BCD) of a copied disk when it is out of line. The program runs it automatically after completion.
Incremental backup
A backup that saves only what changed since the last one, into a small new file. It happens automatically when you pick your existing backup file as the save location. Keep the files together in the same folder.
Image integrity check
A safeguard that automatically verifies your backup file is intact before a restore begins. If the backup is corrupted, the target disk is left untouched.

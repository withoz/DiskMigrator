Copy, back up, and restore an entire Windows disk — a beginner-friendly guide

Before you start The five modes ① Clone ② Backup ③ Restore ④ Fix Boot ⑤ Boot USB FAQ Glossary 한국어

Copy the disk in your current computer — Windows, programs, and files, all of it — onto a new disk, or save it as a single file to bring back later. The copy boots as-is, so there is no need to reinstall Windows.

Examples: move from a slow hard drive to a new SSD, keep a full backup in case of failure, move your system to a new PC

Before you start (please read)

⚠ The target disk is completely erased. Everything on the disk that receives the copy will be gone. Move any important files off it first.

• The program runs with administrator rights (click "Yes" on the blue prompt at launch).

• A USB adapter (external enclosure) for connecting the new disk (M.2/SSD) is handy.

• Depending on the amount of data, it takes 30 minutes to several hours. Do not turn off the computer part-way.

① Disk Clone — step by step

  1. Select the source (the disk to copy, usually marked System) on the left
  2. Select the target (the new disk) on the right — this disk will be erased
  3. Leave the options at their defaults; if the disk is going into a different computer, make sure "Prepare for new hardware" is checked
  4. In the red box, type the target disk's model name exactly (this is a mistake-prevention safeguard)
  5. Click Start Clone → when it finishes, the boot check and repair run automatically
✓ Different sizes are fine. If the target is larger, the extra space is made usable; if it is smaller, the largest partition is shrunk automatically to fit (a notice tells you what will happen). If your actual data won't fit on the target, the app explains why and stops before touching anything.

② Image Backup — step by step

✓ Save your current computer (C:\) into a single file now (recommended)
Even if you replace the disk or it fails, restoring brings everything back exactly as it was.
  1. Select the source disk
  2. Choose the save location — on a different disk than the source; a fast disk is best
  3. Click Start Backup → a single .vhdx file is created (it only takes up as much space as your actual data)
You can also double-click the .vhdx file in File Explorer to browse its contents.
✓ The second time is much faster (incremental backup). On your next backup, pick the previous backup file as the save location — only what changed is saved to a small new file (backup-01.vhdx, and so on). Existing files are never modified; to restore, just pick the most recent file. Keep the files together in the same folder.

③ Image Restore — step by step

  1. Use Browse to pick the .vhdx file you backed up
  2. Select the target disk — it will be erased. If it is smaller, an automatic-shrink notice appears
  3. If the disk will go into a different computer, turn on "Prepare for new hardware" → type the model name → Start Restore
✓ Your backup file is checked automatically. As soon as you pick a file its structure is verified, and when restore starts a deeper check (including the file system) runs before the target is erased. If the backup is corrupted, nothing is written and the target is left untouched.

④ Fix Boot — step by step

A tool for when a cloned or restored disk won't boot. It does not copy anything again.

  1. Connect the disk that wouldn't start to this computer, e.g. with a USB adapter
  2. Select that disk on the Fix Boot tab
  3. Click Check Boot — it only reads, so it is safe
  4. If problems are found, click the Repair Boot button that appears — after repairing, the check runs again automatically
The disk this computer is currently booted from needs no fixing, so repairs are not applied to it. When the check says "ready to boot", put the disk back in its machine and try booting.

⑤ Boot USB — step by step

Make an emergency USB ahead of time, to rescue a computer whose Windows won't start at all. Nothing extra to install — it is built entirely from materials already inside your Windows.

⚠ The USB stick is completely erased. Have an empty USB stick of 8 GB or more ready.
  1. Plug in the USB stick and select it on the Boot USB tab
  2. In the red box, type the USB stick's model name exactly (a mistake-prevention safeguard)
  3. Click Create Boot USB → done in a few minutes

How to use it: when a computer won't start, plug in this USB and power on — DiskMigrator starts automatically. From there you can restore a backup image, clone a disk, or repair the boot configuration, just like normal.

• If the computer doesn't boot from the USB, press the boot-menu key while powering on (F12, F8, ESC, etc., depending on the maker) and pick the USB.
• Making it in advance is the whole point — once a PC is dead, you'd have to build the USB on another computer.

Booting from the copied disk

① Shut the computer down → ② mount the copied disk inside the computer → ③ power on. Done.

It cannot boot while sitting in a USB adapter — it must be mounted internally.

If it won't boot

Don't panic. It is usually just a slightly misaligned boot setting, and it can be fixed. Following ④ Fix Boot — step by step above resolves most cases.

• Right after a clone/restore, the same button is on the completion screen. (It also runs once automatically on completion.)

• If Windows was installed the old way (BIOS) and won't start on a modern computer, use Convert to UEFI on the completion screen.

• If the computer won't turn on at all — so you can't even run this app — boot from the ⑤ Boot USB you made in advance and do the same work there.

Frequently asked questions

QuestionAnswer
Could my source disk get damaged?No. The source is only read. No mode ever modifies the source.
Can I use the computer while it copies?Yes. The snapshot feature copies the disk exactly as it was at the starting moment. Avoiding heavy work is still a good idea.
Why does it ask me to type the model name?It is a safeguard asking whether you really checked which disk will be erased. Type the name exactly as shown in the list.
How long does it take?It depends on how much data is in use and how fast the disks are. Roughly 30–60 minutes per 300 GB.

Glossary

Clone
Copying a disk in its entirety onto another disk. The copy boots as-is.
Image / .vhdx
A single file holding an entire disk. It is a Microsoft-standard format, so File Explorer can open it.
Partition
A section a disk is divided into. There is usually one big section for Windows (C:) and a few small ones for booting.
Boot
The process of Windows starting up when you power on the computer.
Administrator rights
The elevated Windows permission needed to read and write whole disks. A blue confirmation prompt appears at launch.
Snapshot (VSS)
A Windows feature that freezes a "moment in time" of a disk in use and copies that. Files changing during the copy can't corrupt the result.
Smart clone
Skips empty space and copies only actual data, cutting the time dramatically.
Prepare for new hardware (Universal Restore)
Adjusts Windows' internal settings so the copy boots even in a different computer. Always turn it on when moving to another PC.
Automatic shrink
When the target disk is smaller than the source, safely gathers the data forward and shrinks the partition to fit. The source is never touched.
BIOS / UEFI
The base program that runs first when a computer powers on. BIOS is the old way, UEFI is the modern way; recent M.2 disks boot only via UEFI.
MBR / GPT
The scheme used to record how a disk is partitioned. MBR is the old one (paired with BIOS); GPT is the modern one (paired with UEFI).
M.2 / NVMe / SSD
Today's fast, small storage. M.2 is the stick-of-gum shape, NVMe is the fast connection, SSD means solid-state storage.
Fix Boot
Automatically corrects the boot configuration (BCD) of a copied disk when it is out of line. The program runs it automatically after completion.

# 설계 문서

## 화면 정련 계획 (`화면_정련_계획.html`)

v0.6.0의 화면 개편을 설계하며 만든 문서입니다. 브라우저로 열면 됩니다 — 외부 파일을
받지 않으므로 인터넷 없이도 그대로 보입니다.

담긴 것:

- **현재 / 제안 목업 토글** — 같은 화면을 두 가지로 그려 나란히 비교
- **팔레트 비교** — 온화한 색조로 바꾸며 무엇을 왜 남겼는지(경고의 빨강은 일부러 유지)
- **남는 공간 3택 그림 설명** — 그대로 두기 / 마지막에 합치기 / 파티션 조정이 각각
  디스크를 어떻게 바꾸는지
- **막대에서 끌어 조정 프로토타입** — 실제로 끌리는 동작. v0.7.0에서 이대로 구현했습니다.

계획 단계의 문서라 지금 화면과 다른 곳이 있습니다. 특히 항목 이름이
`고른 파티션 넓히기`에서 **`파티션 조정`**으로 바뀌었습니다. 결정의 근거를 남기려고
고치지 않고 그대로 둡니다.

# DiskMigrator 브랜드 자료

로고를 직접 수정할 때 필요한 모든 값을 모았습니다. **왜곡 없는 원본은 이 폴더의 SVG 파일들입니다.**
기존 `docs/assets/logo.png` · `logo.ico` 는 GDI+ 래스터라 D 곡선이 뭉개져 있으니, 아래 SVG에서 다시 내보내십시오.

## 파일

| 파일 | 용도 |
|---|---|
| `mark.svg` | 순수 DM 마크. `currentColor` — 어디에 넣든 글자색을 따라감 |
| `mark-black.svg` | 검정 마크 (밝은 바탕용) |
| `mark-white.svg` | 흰 마크 (어두운 바탕용) |
| `app-icon.svg` | 앱 아이콘 — 다크 라운드 사각 + 흰 마크. **여기서 .ico 재생성** |
| `lockup.html` | 마크 + 워드마크 가로 배치(정식 락업). 라이트/다크 자동 |

## 마크 기하 — 절대 바뀌면 안 되는 값

두 획 모두 **획 굵기 44, 채움 없음**.

```
D:  M22,178 V22 H126 A56,56 0 0 1 126,178 Z    획 이음 = round(둥글게)
M:  M182,100 L255,178 L328,22 V200             획 이음 = miter(각지게), miterlimit 10
```

- D는 둥근 이음, M은 각진 이음 — 이 대비가 로고의 핵심입니다.
- M의 첫 획이 D의 볼(bowl)에서 솟아오르는 "다리 없는 M"입니다.
- 마크 viewBox: `-25 -25 400 272` (사방 25 여백 포함. M 꼭짓점의 뾰족한 miter는 이 여백이 살짝 잘라 평평하게 보입니다 — 의도된 모습).

## 워드마크 (글자)

- 문구: **DISKMIGRATOR** (전부 대문자)
- 글꼴: Segoe UI (system-ui) · 굵기 400(Regular)
- 자간: `letter-spacing: 0.34em`
- 글자 크기: 마크 폭 150px 기준 **23px**

## 락업(마크+글자) 배치

- 순서: 마크 → 세로 구분선 → 워드마크
- 마크와 워드마크 간격: `1.375rem`
- 구분선(1px, 색 = 라이트 `#D9D3CA` / 다크 `#3A3D42`) 왼쪽 여백: `1.375rem`
- 세로 정렬: 가운데

## 앱 아이콘 재생성 방법

1. `app-icon.svg` 를 디자인 도구(Illustrator·Inkscape·Figma)나 온라인 변환기로 엽니다.
2. 16 · 32 · 48 · 64 · 128 · 256 px PNG로 내보냅니다.
3. 그 PNG들을 하나의 `.ico`로 묶습니다.
4. `src/DiskMigrator.App/AppIcon.ico` 를 교체하고 다시 빌드하면 창·작업표시줄 아이콘에 반영됩니다.

> 아이콘 배경 라운드 반경과 마크 위치는 캔버스의 18%로 잡혀 있습니다. 캔버스 크기를 바꾸면
> `app-icon.svg` 주석의 `rx` · `translate` · 여백을 같은 비율로 다시 계산하십시오.
